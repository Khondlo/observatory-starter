START SMALL / BUILD YOUR OWN

One device. One useful question.

The demo works immediately. Your own equipment needs a connection that you configure and verify.

01

Try the demo.

Explore synthetic solar, house and heat-pump readings. Nothing here connects to a real device until you add your own adapter.

02

Bring a reading.

Import the included examples/readings.json file. Use the same JSON format for a reading from your own equipment. W, °C and Hz are different measurements.

Imports stay in this tab’s memory. Reloading returns to demo. Export to keep a copy.

03

Make it yours.

Edit public/config.js to change the title and building labels. Replace the generic house SVG with your own local illustration.

Passwords and tokens belong in a private adapter, never in these browser files.

HOMEY / AN IMPORTANT PART

Start with what already connects.

Homey can expose readings from devices it supports. The included HomeyScript example exports selected capabilities into this starter’s format. You choose the devices and capability IDs.

In the original build, some equipment also used direct local connections. The starter provides a shared data format; it does not include ready-made NIBE, GoodWe, Shelly or Homey login integrations.

THE COLLECTOR / SEPARATE FROM THE SCREEN

Give the readings a memory.

The optional Node recorder reads a local JSON file supplied by your adapter and saves timestamped samples. The local server lets this dashboard load those saved samples.

A NAS or other always-on computer can run that part. Closing this page doesn’t stop a recorder you’ve started separately.

This package is a browser dashboard and local recorder. An installed Android TV app is not included. Large-screen browser view is supported.
